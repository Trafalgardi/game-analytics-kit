Агент для кода работает игровым аналитиком

Поставьте набор в проект игры и просите обычными словами. Агент выгружает сырые события AppMetrica в локальную базу SQLite, разбирается, что значат события именно этой игры, перепроверяет свои числа и выпускает отчёт, который можно переслать кому угодно, — каждый раз в тех же семи блоках.

Открыть живой пример отчёта Звезда на GitHub

Как это работает

  1. Установкаpy install.py <project> кладёт в репозиторий игры семь навыков для Claude Code и Codex и небольшой движок. Ставить через pip ничего не надо.
  2. Подключение«Подключи AppMetrica». Агент найдёт ключ SDK в коде, возьмёт токен только на чтение и выгрузит данные в фоне — с выборкой устройств, если игра большая.
  3. Модель«Собери модель данных». Агент читает каталог событий и код аналитики игры, типизирует параметры, отсекает девайсы разработки, определяет сессии и новых игроков.
  4. Вопросы«Сделай полный анализ за две недели». «Где теряем новичков?» «Что изменила 1.2?» Каждый ответ — версионный отчёт, а выводы остаются в проекте для следующей сессии.

Одна структура для каждого отчёта

Читатель и следующий агент находят одно и то же на одном и том же месте. Отчёт со сломанной структурой или ссылками сборщик не соберёт.

Что внутри

Семь навыков

  • analytics-kit — точка входа и шпаргалка команд
  • analytics-connect-appmetrica — ключ, токен, первая выгрузка
  • analytics-data-model — типизированные события, устройства, сессии
  • analytics-project-audit — что трекает код и что доходит
  • analytics-import-external — выгрузки Google Ads, AdMob, GA4, Play Console
  • analytics-research — вопрос → данные → гипотезы → независимая проверка
  • analytics-report — жёсткая структура, графики, версии

Движок, который можно прочитать

  • Только стандартная библиотека Python, Windows на равных
  • AppMetrica Logs API диапазонами дат, выгрузка отдельным фоновым процессом
  • Выборка устройств и защита диска для игр с 500 тысячами событий в день
  • Стандартные таблицы: ключевые метрики, отвалы, действия по номеру, уходы
  • Самодостаточные HTML-отчёты, светлая и тёмная тема, читаются с телефона
  • Офлайн-самопроверка на синтетике; проверено с настоящими агентами

Быстрый старт

Python 3.11+, git, Claude Code или Codex и игра, которая уже шлёт события в AppMetrica.

git clone https://github.com/Trafalgardi/game-analytics-kit.git <kit>
py <kit>/install.py <project>           # python3 на macOS/Linux

# токен AppMetrica только на чтение, один раз на все проекты:
#   ~/.config/game-analytics-kit/.env  →  APPMETRICA_TOKEN=...

cd <project> && claude                   # или: codex
> Подключи AppMetrica и выгрузи последние две недели.
> Собери модель данных.
> Сделай полный анализ игры за последние две недели.

Полная инструкция — токен по шагам, большие игры, обновление, безопасность, частые проблемы — в README на русском.
